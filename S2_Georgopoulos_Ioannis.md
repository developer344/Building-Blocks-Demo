## Opening the project

- Unity **6.6** (6000.6.4f1)
- Scene: `Assets/Scenes/Magic Room.unity`
- Packages (Meta XR SDK, OpenXR, URP) are resolved automatically by the Package Manager on first open.
- Runs on Meta Quest (Android build profile) or in the Editor with the Meta XR Simulator.

## Experience

- **Locomotion:** teleport and smooth (slide) locomotion with controllers and hands, via the Meta Building Blocks locomotion rig.
- **Grabbable objects:** several imported 3D models on the table (not Unity primitives) that can be picked up with hands or controllers and thrown, with physics and gravity.
- **Environment:** a room enclosed by bookshelves, with colliders on the shelves, table and floor so the player and objects stay inside.
